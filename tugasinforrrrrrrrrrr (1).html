Spesifikasi & Flowchart

Spesifikasi Sistem

  • Fitur: Pencatatan kas, Ringkasan saldo realtime, Tabel riwayat dengan pencarian, Penyimpanan LocalStorage.
  • Struktur Data: Array of Objects (id, keterangan, tipe, nominal, tanggal).
  • Validasi: Tolak input kosong, tolak nominal negatif/nol, batasan maksimal Rp 100 juta, tolak pengeluaran jika melebihi saldo saat ini.

Laporan Vibe Coding

1. Tahap Uji (Skenario & Bug)

Bug yang ditemukan: Pada awalnya, program mengizinkan pengeluaran melebihi uang yang ada. Jika kas Rp 50.000, pengguna bisa menginput pengeluaran Rp 100.000 sehingga kas menjadi minus.

Perbaikan: Menambahkan validasi if (tipe === 'pengeluaran' && nominal > saldoSaatIni) untuk memblokir form dan menampilkan pesan error.

2. Code Review (Penjelasan Kode)

Percabangan: Menggunakan struktur if - else if - else pada saat menekan tombol simpan, bertugas menyaring data kosong atau nominal yang tidak wajar.

Perulangan: Menggunakan forEach untuk membaca data dari dalam LocalStorage dan mencetak baris tag <tr> ke dalam tabel HTML satu per satu.

3. Analisis Etika

Kami tidak memasukkan nama lengkap asli siswa, nomor telepon, atau data pribadi apa pun ke dalam prompt AI. Ini penting untuk mencegah kebocoran data privasi kelas ke sistem server pihak ketiga.

"Aplikasi Manajemen Kas Kelas ini dikembangkan oleh siswa Kelas XI dengan bantuan asisten AI dalam penulisan struktur kode dasar, yang kemudian diperiksa, diuji, dan disempurnakan secara mandiri."
